# E15 Agent 调用治理

← [用户故事地图](../User-Story-Map.md)

## 背景

Gallery 与 A2A 已可调用；缺省权限下的拒绝体验与调用成败的可追查线索仍不完整，运维与安全无法确认「谁被拦下、谁调用失败」。

---

## US-47 无权限客户端调用被拒绝且可感知

**As a** 未获 Agent 调用权限的客户端或终端用户  
**I want** 调用 Agent 或 A2A 时得到明确拒绝  
**So that** 无权访问不会表现为空白成功或无说明错误

### 验收标准

1. **Scenario** 列表或 invoke 被拒绝  
   **GIVEN** 客户端缺少约定的 Agent 调用权限  
   **WHEN** 请求列出或调用受保护 Agent  
   **THEN** 请求失败且响应表明权限不足（非空成功体）

2. **Scenario** 有权限可继续  
   **GIVEN** 客户端已获准调用  
   **WHEN** 发起同等请求  
   **THEN** 请求按现有 Gallery / A2A 行为继续，不因治理层误拦

### 状态

规划中

---

## US-48 调用成败可追查

**As a** 运维或安全责任人  
**I want** 成功与失败的 Agent / A2A 调用留下可查询线索  
**So that** 可核对近期谁调用了什么、何处被拒绝

### 验收标准

1. **Scenario** 失败可查  
   **GIVEN** 一次因权限或上游错误失败的调用  
   **WHEN** 在约定的审计或运维查询入口检索  
   **THEN** 能看到该次失败的时间、主体与结果类别

2. **Scenario** 成功可查  
   **GIVEN** 一次成功的 Gallery invoke 或 A2A 任务  
   **WHEN** 同样入口检索  
   **THEN** 能看到成功记录，且与失败记录可区分

### 状态

规划中
