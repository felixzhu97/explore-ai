# E1 对话与会话

← [用户故事地图](../User-Story-Map.md)

## 背景

用户在 Chat 页与 AI 流式对话、选择可用模型，并在同一会话中连续追问；系统为会话生成标题以便在侧边栏找回。

---

## US-01 AI 对话

**As a** 最终用户  
**I want** 与 AI 助手进行流式对话  
**So that** 我可以快速获得智能回答

### 验收标准

1. **Scenario** 发送消息并看到流式回复
   **GIVEN** 用户处于 Chat 页且会话已就绪  
   **WHEN** 用户输入消息并发送  
   **THEN** 界面以流式方式展示助手回复  
   **AND** 对话结束后完整回答可见

2. **Scenario** 等待回复时可感知进行中
   **GIVEN** 用户已发送一条消息且助手尚未结束回复  
   **WHEN** 用户查看对话区域  
   **THEN** 可看到回复正在生成或更新中

### 状态

已实现

## US-02 Provider / Model 选择

**As a** 最终用户  
**I want** 进入 Chat 页时看到可用的 Provider 与 Model 列表  
**So that** 我可以选择模型且无错误提示

### 验收标准

1. **Scenario** 展示可用 Provider 与 Model
   **GIVEN** 用户打开 Chat 页  
   **WHEN** 页面加载完成  
   **THEN** 展示可用的 Provider 与 Model 列表  
   **AND** 不出现因列表加载失败导致的错误提示（列表可用时）

2. **Scenario** 选择模型后用于对话
   **GIVEN** Provider 与 Model 列表已展示  
   **WHEN** 用户选择某一 Model 并发送消息  
   **THEN** 对话使用所选模型进行回复

### 状态

已实现

## US-03 多轮对话与自动标题

**As a** 最终用户  
**I want** 在同一会话中连续对话并由系统自动生成会话标题  
**So that** 我可以记住上下文并在侧边栏快速找到历史会话

### 验收标准

1. **Scenario** 同会话连续对话保留上下文
   **GIVEN** 用户已在当前会话发送过至少一轮对话  
   **WHEN** 用户继续发送追问  
   **THEN** 助手回复可基于同一会话上下文  
   **AND** 消息仍显示在同一会话中

2. **Scenario** 自动标题出现在侧边栏
   **GIVEN** 用户已在会话中产生足够内容以生成标题  
   **WHEN** 用户查看会话侧边栏  
   **THEN** 该会话显示系统生成的标题  
   **AND** 用户可借此从侧边栏定位该历史会话

### 状态

已实现

## US-03b 会话地址与切换加载

**As a** 最终用户  
**I want** 每个会话有稳定地址，切换时有柔和加载反馈  
**So that** 刷新后仍停留在当前会话，且切换不会误显示成空对话

### 验收标准

1. **Scenario** 有历史的会话地址更新
   **GIVEN** 侧边栏有多个已有消息的会话  
   **WHEN** 用户选择另一会话  
   **THEN** 浏览器地址变为 `/chat/<sessionId>`  
   **AND** 侧边栏仍高亮所选会话

2. **Scenario** 新会话不暴露 id
   **GIVEN** 用户新建或打开尚无消息的会话  
   **WHEN** 会话处于空状态  
   **THEN** 浏览器地址为 `/chat`（不带 sessionId）  
   **AND** 发出第一条消息后地址变为 `/chat/<sessionId>`  
   **AND** 无消息的会话不写入本地持久化  
   **AND** 在 `/chat` 刷新后仍停留在空会话欢迎态，不会自动打开有历史的会话  
   **AND** 尚无消息的会话不出现在侧边栏会话列表（发出第一条消息后才进入列表）

3. **Scenario** 首条回复在地址升级后仍实时出现
   **GIVEN** 用户在空会话 `/chat` 发出第一条消息  
   **WHEN** 地址升级为 `/chat/<sessionId>`  
   **THEN** 助手回复在当前页面流式出现，无需刷新  
   **AND** 「思考中」占位在回复完成后消失

4. **Scenario** 刷新恢复当前会话
   **GIVEN** 用户正在查看 `/chat/<sessionId>`  
   **WHEN** 用户刷新页面  
   **THEN** 仍停留在同一会话并展示其消息历史

5. **Scenario** 切换时显示加载占位
   **GIVEN** 用户选择另一尚未展示历史的会话  
   **WHEN** 历史消息加载中  
   **THEN** 显示轻量加载占位而非欢迎空态  
   **AND** 加载结束后展示消息（或真·空会话欢迎页）

6. **Scenario** 非法或他人会话重定向
   **GIVEN** 地址为不存在或不属于当前身份的 `/chat/<sessionId>`  
   **WHEN** 页面尝试打开该会话  
   **THEN** 直接重定向到 `/chat`，不展示他人内容  
   **AND** 不出现 toast / 错误通知条

### 状态

已实现

## US-03c 聊天中的结构图

**As a** 最终用户  
**I want** 助手回复中的结构图以图片形式展示  
**So that** 我可以在对话内看懂时序与类设计，而无需拷到站外工具

### 验收标准

1. **Scenario** 完整时序图以图展示
   **GIVEN** 助手回复包含完整的时序结构图  
   **WHEN** 用户在聊天中查看该回复  
   **THEN** 结构图以图片形式展示  
   **AND** 周围正文仍可读

2. **Scenario** 完整类图以图展示
   **GIVEN** 助手回复包含完整的类结构图  
   **WHEN** 用户在聊天中查看该回复  
   **THEN** 结构图以图片形式展示

3. **Scenario** 流式未完成的图保持平静
   **GIVEN** 结构图仍在流式生成且尚未闭合  
   **WHEN** 用户查看回复  
   **THEN** 其余回复内容仍可读  
   **AND** 界面不出现失败或空图壳

4. **Scenario** 非法图源保留源码与提示
   **GIVEN** 助手回复包含无法绘制的结构图源码  
   **WHEN** 用户查看回复  
   **THEN** 原始源码仍可见  
   **AND** 显示简短平静提示说明无法绘制

5. **Scenario** 普通代码块仍是代码
   **GIVEN** 助手回复包含非结构图的普通围栏代码块  
   **WHEN** 用户查看回复  
   **THEN** 该块仍以代码块展示

6. **Scenario** 点击结构图可全屏查看
   **GIVEN** 助手回复中已展示结构图  
   **WHEN** 用户点击该图  
   **THEN** 结构图以全屏层展示  
   **AND** 可关闭回到对话  
   **AND** 聊天内联图不展示悬停工具按钮

7. **Scenario** 全屏中可下载结构图
   **GIVEN** 用户已打开结构图全屏层  
   **WHEN** 用户选择下载  
   **THEN** 浏览器下载 SVG 文件

### 状态

已实现

## US-03d 聊天中的丰富数据图

**As a** 最终用户  
**I want** 助手回复中支持更丰富的数据图（含多系列与专用布局）  
**So that** 我可以在对话内比较趋势、分布与多维得分，而无需离开会话

### 验收标准

1. **Scenario** 专用图类型以图展示  
   **GIVEN** 助手回复包含完整的散点 / 雷达 / 热力 / 漏斗 / 仪表盘数据图  
   **WHEN** 用户在聊天中查看该回复  
   **THEN** 图表以可读图片展示  
   **AND** 周围正文仍可读

2. **Scenario** 多系列对比图  
   **GIVEN** 用户要求在同一类别上比较两个及以上系列  
   **WHEN** 助手返回完整多系列图  
   **THEN** 各系列在图中可区分  
   **AND** 图例或标签能标识系列

3. **Scenario** 趋势与量组合图  
   **GIVEN** 用户要求同时看趋势与量  
   **WHEN** 助手返回完整组合图  
   **THEN** 两种度量出现在同一图中且标签不互相遮挡

4. **Scenario** 原有简单图仍可用  
   **GIVEN** 助手回复包含完整的柱状 / 折线 / 饼 / 圆环图  
   **WHEN** 用户查看回复  
   **THEN** 图表仍按原方式展示

5. **Scenario** 结构图仍是结构图  
   **GIVEN** 用户要求时序或类结构图  
   **WHEN** 助手回复  
   **THEN** 以结构图图片展示  
   **AND** 不以数据图呈现

6. **Scenario** 无数据或非法图保持平静  
   **GIVEN** 工具结果缺少可用数字或图表载荷无效  
   **WHEN** 用户查看回复  
   **THEN** 界面不出现损坏的空图壳  
   **AND** 用户仍能看到可读正文或简短平静说明

### 状态
