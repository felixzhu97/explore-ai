# E2 隐私与隔离

← [用户故事地图](../User-Story-Map.md)

## 背景

访客使用 ExploreAI 时，聊天会话按浏览器隔离；并提供隐私说明、分析 Cookie 选择与本浏览器数据擦除。

---

## US-04 按浏览器隔离聊天会话

**As a** 使用 ExploreAI 的访客  
**I want** 我的聊天会话只对本浏览器可见  
**So that** 其他电脑无法看到或操作我的对话

### 验收标准

1. **Scenario** 本浏览器可见自己的会话
   **GIVEN** 访客已在当前浏览器产生聊天会话  
   **WHEN** 访客在同一浏览器再次打开应用  
   **THEN** 仍可看到或继续本浏览器下的会话

2. **Scenario** 其他电脑看不到该访客会话
   **GIVEN** 访客仅在浏览器 A 使用过 ExploreAI  
   **WHEN** 在另一台电脑或另一浏览器打开应用  
   **THEN** 不展示浏览器 A 中的聊天会话  
   **AND** 无法操作浏览器 A 中的对话

### 状态

已实现

## US-05 欧盟隐私告知、同意与擦除控制

**As a** 使用 ExploreAI 的访客  
**I want** 看到隐私说明、选择分析 Cookie，并能擦除本浏览器数据  
**So that** 我了解处理目的并行使基本隐私控制

### 验收标准

1. **Scenario** 查看隐私说明并选择分析 Cookie
   **GIVEN** 访客使用 ExploreAI  
   **WHEN** 访客打开隐私相关说明或同意控件  
   **THEN** 可看到隐私说明  
   **AND** 可选择是否启用分析 Cookie

2. **Scenario** 擦除本浏览器数据
   **GIVEN** 访客本浏览器已有相关本地或会话数据  
   **WHEN** 访客执行擦除本浏览器数据  
   **THEN** 本浏览器相关数据被清除  
   **AND** 访客可继续以干净状态使用应用

### 状态

已实现

## US-05b 政策中转页与法律文档

**As a** 使用 ExploreAI 的访客  
**I want** 从帮助菜单进入政策索引或隐私控制，并阅读使用条款与隐私政策等文档  
**So that** 我在两级菜单内即可了解服务规则与数据处理方式（无三级菜单）

### 验收标准

1. **Scenario** 打开政策中转页  
   **GIVEN** 访客使用 ExploreAI  
   **WHEN** 访客从帮助 → 政策打开中转页或访问 `/policies`  
   **THEN** 看到使用条款、隐私政策、Cookie 政策、子处理方的摘要列表  
   **AND** 帮助子菜单仅含「政策」与「隐私」两项（政策正文从中转页进入）

2. **Scenario** 阅读政策正文  
   **GIVEN** 访客在政策中转页  
   **WHEN** 访客打开使用条款或隐私政策  
   **THEN** 看到分章节的政策正文与更新日期  
   **AND** 正文语言与当前界面语言一致（en / zh / ja / fr / es）

3. **Scenario** 旧法律链接仍可用  
   **GIVEN** 访客持有旧的 `/legal/...` 书签  
   **WHEN** 打开该地址  
   **THEN** 被带到对应的 `/policies/<slug>` 文档

### 状态

已实现（Jira: [AI-339](https://felixzhu.atlassian.net/browse/AI-339)）
