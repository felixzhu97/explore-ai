# E3 RAG 与视觉

← [用户故事地图](../User-Story-Map.md)

## 背景

用户可上传文档做知识问答，也可结合图片与文档做多模态问答，或在独立页面做图像描述、检测与 OCR。

---

## US-06 RAG 知识问答

**As a** 最终用户  
**I want** 上传文档并基于文档内容提问  
**So that** AI 回答有据可查

### 验收标准

1. **Scenario** 上传文档后基于内容提问
   **GIVEN** 用户已上传可用于问答的文档  
   **WHEN** 用户就文档内容提问  
   **THEN** AI 基于文档内容给出回答  
   **AND** 回答可对应到文档依据（有据可查）

2. **Scenario** 未提供文档时无法依赖文档回答
   **GIVEN** 用户尚未上传相关文档  
   **WHEN** 用户发起依赖文档的知识问答  
   **THEN** 系统不表现为已基于该文档作答  
   **AND** 用户可先上传文档再提问

### 状态

已实现

## US-07 Vision 多模态 RAG

**As a** 最终用户  
**I want** 在文档问答中专注文本提问与文档依据  
**So that** 输入区不被附图控件打断（图像分析走独立视觉页）

### 验收标准

1. **Scenario** 文档问答作曲家无附图入口
   **GIVEN** 用户打开文档问答  
   **WHEN** 查看消息输入区  
   **THEN** 输入框左侧无图片按钮  
   **AND** 仍可通过侧栏上传文档后提问

2. **Scenario** 图像分析走独立能力
   **GIVEN** 用户需要描述 / 检测 / OCR  
   **WHEN** 打开独立图像分析页  
   **THEN** 可完成结构化视觉分析（见 US-08）

### 状态

已实现（Jira: [AI-340](https://felixzhu.atlassian.net/browse/AI-340)；Doc Q&A 附图入口已移除）

## US-08 图像分析（独立）

**As a** 最终用户  
**I want** 在独立页面完成图像描述、目标检测与 OCR  
**So that** 无需进入 RAG 对话即可获得结构化视觉分析结果

### 验收标准

1. **Scenario** 独立页完成描述、检测与 OCR
   **GIVEN** 用户打开独立图像分析页面并提供图像  
   **WHEN** 用户触发图像分析  
   **THEN** 可获得图像描述、目标检测与 OCR 相关结果  
   **AND** 无需进入 RAG 对话页即可完成

2. **Scenario** 结果为结构化视觉分析
   **GIVEN** 图像分析已成功完成  
   **WHEN** 用户查看结果区域  
   **THEN** 结果以可阅读的结构化形式展示（描述 / 检测 / OCR 等）

### 状态

已实现
